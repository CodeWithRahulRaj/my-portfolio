# Setup Commands Executed by AI

The following terminal commands were executed by the AI to build this Next.js portfolio project from scratch:

## 1. Scaffold Next.js Application
```bash
npx create-next-app@latest my-portfolio \
  --typescript \
  --tailwind \
  --eslint \
  --app \
  --src-dir \
  --import-alias "@/*" \
  --use-npm \
  --yes
```

## 2. Install Dependencies
```bash
cd my-portfolio
npm install lucide-react   # UI glyphs (menu, chevron)
npm install react-icons    # brand logos for the Skills screen
```

## 3. Project Configuration Updates
```bash
# Remove the default Next.js config generated by scaffolding
rm next.config.ts

# Create the required next.config.mjs for static exports
cat << 'EOF' > next.config.mjs
/** @type {import('next').NextConfig} */
const nextConfig = {
  output: 'export',
  images: {
    unoptimized: true,
  },
};
export default nextConfig;
EOF
```

## 4. Folder Architecture Setup
```bash
mkdir -p public/images \
  src/app/{projects,skills,experience,contact} \
  src/components/{layout,sections,ui} \
  src/data src/types src/lib
```

## 5. Image Extraction (macOS built-in Swift)
The AI executed Swift scripts utilizing CoreGraphics to precisely crop the avatar and project thumbnails directly from `figmaDesign.png` without relying on external dependencies like Python's PIL.
```bash
# Rebuild every asset in public/images from ../figmaDesign.png:
./ai-resources/scripts/extract_assets.sh

# The driver compiles two helpers:
#   crop.swift   – crops a CGRect out of the canvas (optionally upscaled)
#   cutout.swift – flood-fills the studio backdrop to transparency so the
#                  hero portrait can sit on the CSS gradient
```

## 6. Build and Validation Tests
```bash
# Compile and build the static export to `out/`
npm run build

# Run lint checks to ensure zero warnings/errors
npm run lint
```
